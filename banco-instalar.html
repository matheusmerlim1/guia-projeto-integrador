Instalar o banco

A diferença entre MariaDB e MySQL, a instalação no Windows e a conferência de que tudo ficou funcionando.

5.1 MariaDB ou MySQL

O MariaDB nasceu de uma cópia do código do MySQL e continua compatível com ele: o mesmo SQL, a mesma porta (3306) e os mesmos drivers. O projeto funciona igual com os dois — todos os testes e rotas desta etapa foram executados nos dois bancos. Escolha um e siga os passos; a escolha abaixo troca as instruções e as respostas dos terminais.

5.2 Instalar no Windows

  1. Baixe o instalador

    Em mariadb.org/download, escolha a versão 11.4, o sistema Windows, a arquitetura x86_64 e o pacote MSI.

  2. Defina a senha do root

    No instalador, na tela de configurações do usuário, defina a senha do usuário root — no exemplo, root — e marque a opção de usar UTF-8 como conjunto de caracteres padrão.

  3. Instale como serviço

    Mantenha a instalação como serviço do Windows, com o nome MariaDB e a porta 3306. Assim o banco inicia junto com o computador. O HeidiSQL, uma ferramenta gráfica para ver as tabelas, vem junto.

  4. Coloque a pasta bin no PATH

    Para usar o mariadb e o mysql em qualquer pasta, adicione C:\Program Files\MariaDB 11.4\bin à variável Path: pesquise “variáveis de ambiente” no menu Iniciar, abra Variáveis de Ambiente, selecione Path, clique em Editar e em Novo. Depois, feche e abra o Prompt de Comando.

  1. Baixe o instalador

    Em dev.mysql.com/downloads/mysql, escolha MySQL Community Server 8.4, sistema Microsoft Windows, e baixe o MSI Installer. Não é preciso criar conta: use o link para apenas iniciar o download.

  2. Instale e abra o configurador

    Siga a instalação típica. Ao final, o MySQL Configurator é aberto para configurar o servidor.

  3. Defina a senha do root e o serviço

    Em Accounts and Roles, defina a senha do usuário root — no exemplo, root. Em Windows Service, mantenha o serviço iniciando com o Windows e a porta 3306.

  4. Coloque a pasta bin no PATH

    Para usar o mysql em qualquer pasta, adicione C:\Program Files\MySQL\MySQL Server 8.4\bin à variável Path: pesquise “variáveis de ambiente” no menu Iniciar, abra Variáveis de Ambiente, selecione Path, clique em Editar e em Novo. Depois, feche e abra o Prompt de Comando.

Senha só para estudo

A senha root facilita o exemplo, porque é a mesma usada nos scripts e nas conexões do projeto. Em um servidor de verdade, use uma senha forte e um usuário próprio para a aplicação.
