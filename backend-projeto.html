A ordem de construção do back-end, a configuração do projeto, as dependências e as interfaces dos repositórios.

A ordem de construção

O back-end é construído de dentro para fora, seguindo a arquitetura: primeiro as entidades e seus testes (Etapa 0), depois as interfaces dos repositórios, o gestor com seus testes e, por fim, as rotas. O acesso ao banco de dados fica para a Etapa 5: graças às interfaces, tudo o que vem antes é testado sem banco.

4.1 Configurar o projeto e instalar as dependências

O arquivo de configuração lista as bibliotecas usadas e os scripts: apelidos para os comandos do dia a dia, como iniciar a API, rodar os testes e recriar o banco.

4.2 Escrever os contratos: as interfaces dos repositórios

Antes de pensar em banco de dados, defina o que o gestor precisa ler e gravar. A interface lista os métodos, sem implementação. O gestor vai depender dela, e não de uma classe concreta.
