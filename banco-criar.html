5.4 Criar o banco com scripts

O banco é criado por arquivos .sql guardados no projeto. Assim qualquer pessoa do grupo recria o mesmo banco com um comando, e as mudanças na estrutura ficam registradas no Git.

  • estrutura.sql apaga e cria o banco e as tabelas.
  • dados.sql carrega os dados para usar a aplicação. As datas usam CURDATE(), então sempre há um empréstimo atrasado e outro no prazo.
  • dados-teste.sql carrega dados fixos, que os testes conhecem de antemão.
  • Os dois arquivos de dados começam com SET NAMES utf8mb4;. Sem essa linha, o cliente do MySQL no Windows lê os acentos com a codificação do terminal e grava “O CortiÃ§o” no lugar de “O Cortiço”.

O repositório transforma objetos em comandos SQL e linhas em objetos. Os valores nunca são colados no texto do SQL: vão pelos ?, em consultas preparadas, o que impede SQL Injection — um ataque em que o usuário digita SQL em um campo.
