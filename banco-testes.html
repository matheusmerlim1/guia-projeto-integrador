Testes de integração e rotas

Testes que usam o banco de verdade e como conferir as rotas da API pelo terminal, antes de existir qualquer tela.

5.6 Testes de integração

Os testes de unidade da Etapa 4 usam dublês. Os de integração usam o banco de verdade, para confirmar que o SQL funciona. Antes de cada teste, o banco é recriado com dados-teste.sql, então cada teste sabe exatamente o que encontra.

5.7 Testar as rotas antes da tela

Com o banco pronto, os dados iniciais carregados e a API rodando, cada rota pode ser testada pelo terminal. Assim, quando a tela não funcionar, já se sabe que o problema não está na API.
