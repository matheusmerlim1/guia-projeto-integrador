4.7 Criar as rotas da API

As rotas ligam cada endereço HTTP a uma ação do gestor. Elas não têm regra de negócio: recebem a requisição, chamam o gestor e enviam a resposta em JSON, com o código de status adequado.

Rota O que faz Sucesso Erro
GET /emprestimosLista os empréstimos em aberto, com prazo e multa200500 se o banco falhar
POST /emprestimosRegistra um empréstimo. Corpo: { "livroId": 1, "leitorId": 2 }201 criado400 se uma regra impedir
PATCH /emprestimos/{id}/devolucaoRegistra a devolução e informa a multa200400 se já devolvido
GET /livros e GET /leitoresListam as opções do formulário200500 se o banco falhar

Por que CORS

O front-end roda em localhost:5173 e a API em localhost:8080. Por segurança, o navegador bloqueia requisições entre endereços diferentes, a menos que a API autorize. É isso que o CORS faz.
